# Project Title

## Project Option
Website or Simple Browser Game

## Project Description
Describe the completed experience.

## Theme Interpretation
The clothing this fictional brand advertises and sells is all based off of sci-fi and outer space related concepts, hence the name "Gemini Garments". 
It's not merely a seasonal drop, but something the site and brand would play into all year round.

## Intended User or Player
This site is designed for teenagers/young adults with an interest in streetwear and a knowledge of sci-fi and contemporary media in general. 
Desktop and mobile users are to both be accommodated. ​

## User or Player Goal
The main goal for this site is for users to browse clothing drops, learning about what inspires the designer(s) of the clothing for the brand, and having 
an immersive experience while in the storefront. ​

## Main Features
The major features/sections of this site are the navigation menu, the hero carousel, the featured collection, quick links, and an about section. 

## JavaScript Features
Hero carousel, which allows the user to cycle through different collections, acting as a CTA. "View Details" buttons on products. The newsletter checks for valid emails.

## Responsive Design
The navigation menu turns into a grid, and the featured collection vertically stacks, along with quick links, and the images in the hero carousel compress.

## User Testing
I didn't get the chance to have any users test my site, but I observed that my site needed improved typography, assets to be implemented, and improved functionality for my quick links. 

## Revisions
Typography, quick links directed to actual external sites, and asset implementation.
